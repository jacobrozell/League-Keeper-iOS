# 1.0 ship checklist

Gate for App Store submission. Check each item before submitting for review.

**Last updated:** 2026-06-16

---

## Code & quality

- [ ] `main` branch CI green (lint + unit tests)
- [ ] Nightly UI tests passing
- [ ] No known crashers in TestFlight week
- [ ] Version/build bumped in `project.yml`

---

## App assets

- [ ] App icon 1024×1024 in `Assets.xcassets`
- [ ] Screenshots for required device sizes
- [ ] App Store copy pasted from [app-store-listing.md](../app-store-listing.md)

---

## Legal & URLs

- [ ] GitHub Pages enabled ([github-pages.md](../github-pages.md))
- [ ] Privacy URL live and matches [privacy.html](../privacy.html)
- [ ] Support URL live and matches [support.html](../support.html)
- [ ] Privacy nutrition labels accurate in App Store Connect

---

## Accessibility

- [ ] [Manual_todo.md](../../accessibility/Manual_todo.md) core flow VoiceOver complete
- [ ] AXXXL spot-check on new tournament + tournament detail
- [ ] [accessibility.html](../accessibility.html) reflects actual behavior
- [ ] WCAG tracker: zero Required **Fail** on core flow screens

---

## Firebase (if enabled in Release)

- [ ] Production `GoogleService-Info.plist` in archive (not committed)
- [ ] Analytics events appear in Firebase DebugView (test build)
- [ ] Crashlytics receives test non-fatal (optional)

---

## TestFlight

- [ ] Internal testers signed off on core flow
- [ ] At least one full tournament played on physical device
- [ ] iPad smoke test completed

---

## App Store Connect

- [ ] Build selected for review
- [ ] Export compliance answered
- [ ] Age rating questionnaire complete
- [ ] Review notes include test account steps (if needed — N/A for no-login app)

---

## Post-submit

- [ ] Tag release in git (`v1.0.0`)
- [ ] Update [CHANGELOG.md](../../CHANGELOG.md)
- [ ] Monitor Crashlytics + reviews first 48 hours
