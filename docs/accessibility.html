League Keeper is built with SwiftUI and supports VoiceOver, Dynamic Type, and semantic system colors for light and dark mode.

WCAG 2.1 AA

We track accessibility compliance per screen. Current status: in progress (automated audits on tab screens; manual VoiceOver sign-off pending before App Store).

Tracker (source): WCAG rollup on GitHub

Features

  • Accessibility labels and identifiers on interactive controls
  • Minimum 44pt touch targets on primary actions
  • Dynamic Type support up to accessibility sizes on key screens
  • Automated accessibility audits in the UI test suite
