# Evidence storage

Place verification artifacts here or link to repo paths.

## Layout

```text
evidence/
  voiceover/          # VoiceOver spot-check notes
  dynamic-type/       # AXXXL screenshots
  contrast/           # Computed ratio notes
  layout/             # iPad + landscape reflow matrix (P-1.4.10)
  orientation/        # Portrait/landscape matrix (legacy alias)
```

## Naming convention

`{screen-id}_{check}_{device}_{theme}_{orientation}.{png|md}`

Example: `tournament-detail_voiceover_iphone17_light_portrait.md`
